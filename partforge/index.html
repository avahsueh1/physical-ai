      Robot pins

      A part can drive if its pins use these names. “This circuit (live)” drives with whatever is on the board, edits included.

      lineL, lineR
      in: the left or right front sensor sees the line
      bump
      in: hit the edge of the table
      motorL, motorR
      out: turn that wheel forward
      revL, revR
      out: turn that wheel backward (optional)
      Use it from code 
      const { lib, circuit } = PartForge;
lib.define({ id: 'Spinner', name: 'Spinner',
  circuit: circuit(
    [['h', 'HIGH', 40, 60],
     ['l', 'OUT', 300, 40, 'motorL'],
     ['r', 'OUT', 300, 100, 'revR']],
    ['h.out -> l.in', 'h.out -> r.in']) });
PartForge.refresh(); // save it and show it in the lists
